# Changelog

## 1.2 — versionCode 3

- Главный экран: занято/свободно в хранилище и доступная ОЗУ.
- «Большие файлы»: файлы от 20 МБ, топ-300, открытие через системный просмотрщик и удаление.
- «Дубликаты»: поиск по размеру и MD5, группы, удаление лишних копий.
- «Размер папок»: рекурсивный подсчёт по корню внешнего хранилища.
- «Приложения»: пользовательские приложения, размеры через `StorageStatsManager`, удаление и настройки.
- «Ускорение и кэш» через Shizuku: `pm trim-caches`, `am kill-all`, отключение рекламных модулей MIUI/Facebook, `bg-dexopt`, анимации 0.5x.
- Собственный read-only `content://` провайдер для безопасного открытия файлов.
- Подпись APK, сборка без Gradle.
